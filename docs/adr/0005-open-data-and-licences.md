# ADR 0005 - Open data only, with licences and provenance

Date: 2026-09-16 · Status: accepted

## Context
Vehicle data is widely available, but mostly under restrictive terms (marketplaces, commercial databases, scraped sites). A public repository and API must be able to show, for every value, where it came from and that it may be redistributed.

## Decision
- Four sources only: **EEA CO2 monitoring** (CC BY 4.0, "Source: European Environment Agency (EEA)"), **DRPCIV Parc auto România** on data.gov.ro (OGL-ROU 1.0, Romanian and English attribution), **Wikidata** (CC0), **NHTSA vPIC** (US public domain). Admitted licence ids: `CC-BY-4.0`, `OGL-ROU-1.0`, `CC0-1.0`, `US-PD`.
- **No share-alike** data (it would bind the whole dataset), **no scraping**, no marketplace or price data, no hand-typed vehicle data.
- **Provenance per record**: every import writes `vd_record_sources`; single-record responses carry `sources[]` (key, licence, attribution, retrieval time); snapshots carry `X-Data-Licences` and a `rel="license"` link.
- **Logos by reference only**: the Wikimedia Commons file name and licence, accepted only for public domain, CC0 or CC BY without SA; never copied into the repository or served as files. A trademark notice states that logos remain their owners' marks and imply no endorsement.
- Fixtures (at most 200 rows each) are generated by `scripts/fetch_fixtures.sh` and listed with checksums in `docs/data-sources.md`; `vehicle:sources check` fails the release otherwise.

## Consequences
Coverage is limited to what public bodies publish (no body type, gearbox or colour yet). Reusers must show attributions, which the API hands them per record. A new source needs a licence review and an ADR.
