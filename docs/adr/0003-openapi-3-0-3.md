# ADR 0003 — OpenAPI 3.0.3 instead of 3.1

Date: 2026-09-16 · Status: accepted

## Context
The design specified OpenAPI 3.1. Response validation in PHP (Spectator 3.0.4 → cebe/php-openapi 1.8; league/openapi-psr7-validator 0.24) parses only 3.0.x documents.

## Decision
The contract is written in OpenAPI 3.0.3 with `nullable: true` for class-2 values. Spectral, oasdiff and Scalar accept both versions, so nothing else changes.

## Consequences
Migrating to 3.1 later is mechanical (`nullable` → `type: [T, "null"]`) and becomes possible when the PHP validators support it. Contract tests run on every PR, which is worth more than the newer syntax.
